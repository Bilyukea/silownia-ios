# Siłownia — iPhone + Apple Watch

Нативная версия Gym Plan Tracker: программы беговой дорожки с переходами по пульсу (часы), позже — силовые и журнал.

## Как устроено

- `project.yml` — описание проекта для [XcodeGen](https://github.com/yonaskolb/XcodeGen); `.xcodeproj` генерируется в облаке и в репозитории не хранится.
- `Shared/` — общая логика: программы (`TreadmillProgram`), ход программы и переходы по пульсу (`ProgramRunner`).
- `Watch/` — приложение для часов: HealthKit‑сессия, главный экран, график пульса, вся программа (страницы колёсиком).
- `iOS/` — приложение для iPhone.
- `codemagic.yaml` — облачные сборки, только ручной запуск.

## Сборки в Codemagic

- **check** — только компиляция (2–4 мин). Запускать после каждой правки.
- **ipa** — неподписанный `Silownia-unsigned.ipa` для установки через Sideloadly.

## Установка без Apple Developer Program

1. Скачать `Silownia-unsigned.ipa` из артефактов сборки **ipa**.
2. Подключить iPhone к компьютеру, открыть Sideloadly, перетащить IPA, ввести Apple ID, Start.
3. На iPhone: Настройки → Основные → VPN и управление устройством → доверять своему Apple ID.
4. Повторять каждые 7 дней (данные сохраняются).
